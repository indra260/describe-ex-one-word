Entry for the make.fun competition
[Describe Your Ex in One Word](https://make.fun/c/u-puan-describe-your-ex-in-one-word-9fc6ebe7):
a single word that sums up an ex — the relationship, filed under spam.

> unsubscribe

## Why this word

The judge rewards a word that lands as a joke at a glance, through an
unexpected angle rather than a plain insult. *Unsubscribe* treats the ex
like a newsletter nobody remembers signing up for: one click, no reply,
gone from the inbox. Everyone who has had an ex recognises the feeling —
the laugh comes with a nod.

## Run

```sh
python3 main.py
```

The program writes the word to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory for local testing).
It validates the competition gate first: exactly one word, 1–111 characters.
